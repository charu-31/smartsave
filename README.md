# SmartSave AI 💰

SmartSave AI is an intelligent personal finance tracker designed to help users manage their money efficiently. It allows users to track income and expenses, create budgets, set savings goals, receive bill reminders, and gain AI-powered financial insights.

## Features 🚀

* User Authentication (Register / Login / Logout)
* Add and Manage Expenses
* Add and Manage Income
* Budget Planning and Tracking
* Smart Budget Splitter
* Goal Planning with Forecasting
* AI Financial Insights
* Monthly Expense Trend Analysis
* Expense Distribution Charts
* Savings Streak Tracker
* Bill Reminder System
* Search and Filter Expenses
* View / Delete Expenses
* PDF Monthly Report Generation
* User-specific Data Security
* Mobile-friendly Dashboard

## Tech Stack 🛠️

* Python
* Flask
* SQLite3
* HTML
* CSS
* Bootstrap
* Plotly
* ReportLab

## Installation ⚙️

Clone the repository:

git clone https://github.com/your-username/smartsave-ai.git

Move into project directory:

cd smartsave-ai

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

## Project Structure 

* app.py → Main Flask application
* templates/ → HTML pages
* static/ → CSS and assets
* finance.db → Database
* requirements.txt → Dependencies
